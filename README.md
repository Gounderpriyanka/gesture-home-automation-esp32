
# 🏠 Gesture-Based Smart Home Automation using Machine Learning

## 🚀 Project Overview

This project presents a smart home automation system that allows users to control devices using hand gestures. The system uses computer vision and machine learning techniques to detect hand gestures in real time and perform actions accordingly.

It is a touchless, user-friendly, and cost-effective solution for controlling appliances.

---

## 💡 Key Features

* ✋ Hand gesture recognition using webcam
* ⚡ Real-time device control
* 💡 LED ON/OFF using gestures
* 🌀 Fan ON/OFF using gestures
* 🧠 Machine Learning-based detection
* 🚫 No physical switches required

---

## 🛠️ Technologies Used

* Python
* OpenCV
* MediaPipe
* Computer Vision
* Machine Learning

---

## ⚙️ How It Works

1. The webcam captures live video input
2. Hand is detected using MediaPipe
3. Finger counting logic is applied
4. Based on gesture:

   * 1 Finger → LED ON
   * 0 Finger → LED OFF
   * 2 Fingers → Fan ON
   * 3 Fingers → Fan OFF
5. The system performs actions in real time

---
